## Несколько слов о себе

Я Python‑разработчик, увлечённый созданием функциональных веб‑приложений и интерактивных решений. Выбрала эту профессию, потому что программирование сочетает логику, творчество и возможность видеть реальный результат своей работы: код превращается в работающий продукт, который может быть полезен людям.

Моя мотивация — постоянно развиваться в области веб‑разработки, углублять знания Python и смежных технологий, а также участвовать в создании масштабируемых и удобных для пользователя сервисов.

Опыт, который поможет мне на новой роли:
* прохождение полного курса по веб‑разработке в Яндекс Практикуме;
* разработка локальной игры с применением принципов ООП и библиотеки Pygame;
* создание двух полнофункциональных веб‑приложений с интеграцией фронтенда и бэкенда;
* работа с REST API: проектирование эндпоинтов, обработка запросов, реализация CRUD‑операций;
* развёртывание приложений на удалённом сервере с использованием Docker, Nginx и Gunicorn;
* командная разработка API для веб‑сервиса;
* работа с реляционными базами данных и написание SQL‑запросов;
* использование Git для контроля версий и командной разработки.
